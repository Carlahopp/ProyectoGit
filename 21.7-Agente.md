# Proyecto: Asistente de IA para el Análisis de Registros (Logs)
Este repositorio contiene la configuración, documentación y pruebas del asistente de IA desarrollado en **TextCortex** para la automatización del diagnóstico de fallas en entornos de servidores y aplicaciones.

## 👤 1. Configuración del Perfil (Persona)
* **Nombre del Perfil:** Analista Senior de SysOps / DevOps
* **Rol:** Ingeniero experto en confiabilidad de sitios (SRE).
* **Tono y Estilo:** Claro, conciso, analítico y centrado en los puntos clave. Sin rodeos ni introducciones genéricas.

## 📝 2. Configuración de la Plantilla / Habilidad (Skill)
* **Nombre de la Habilidad:** `analizador-diagnostico-logs`
* **Etiquetas:** `Sistemas`, `DevOps`, `Práctica`
* **Prompt Base Utilizado:**
  > Actúa como un Analista Senior de SysOps / DevOps. Analiza el bloque de registros técnicos (logs) que el usuario proporcione a continuación y genera un reporte estructurado bajo los siguientes puntos:
  > 1. **Resumen del Error:** Identifica de forma muy breve el error principal, la marca de tiempo (timestamp) y el componente afectado.
  > 2. **Detección de Patrones:** Señala si hay fallas en cascada, reintentos fallidos o códigos de estado específicos.
  > 3. **Clasificación y Gravedad:** Agrupa el problema en una categoría común y asígnale un nivel de severidad (CRÍTICO, ALTO, MEDIO o BAJO), incluyendo una acción rápida de mitigación.

## 🧪 3. Resultados de las Pruebas de Validación
El asistente fue validado con tres escenarios críticos de infraestructura, entregando reportes técnicos eficientes:
1. **Saturación de Base de Datos:** Detectó un bloqueo en el pool de conexiones (`100/100`) a las marcas de tiempo especificadas y asignó una gravedad **ALTA**.
2. **Seguridad / Autenticación:** Identificó patrones de ataques de fuerza bruta (múltiples inicios de sesión fallidos desde una misma IP en un intervalo de 6 segundos).
3. **Fallo de Software:** Interpretó correctamente excepciones de código de la aplicación (`NullPointerException`).

## 🌍 4. Implementación y Automatización Futura
* **Casos de Uso Real:** Monitoreo automatizado en clínicas de salud, centros de datos y portales de e-commerce para alertar a los equipos de soporte en tiempo real.
* **Automatización sugerida:** Integración de la API de TextCortex mediante plataformas como Zapier o Make para enviar resúmenes automatizados a canales de Slack, Discord o correos electrónicos del equipo de guardia.
